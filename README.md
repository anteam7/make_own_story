# make_own_story

직접 쓰는 글을 Claude와 함께 다듬으며 버전 관리하는 저장소.

## 작품

- [괴이박멸사무소](괴이박멸사무소/)

## 구조

```
괴이박멸사무소/
├── 본문/    회차별 원고 (001_도입부.md …)
└── 설정/    복선, 인물, 세계관 등 설정 메모
```

## 작업 방식

- 원고를 수정할 때는 커밋을 나눠서 남긴다. 처음 쓴 원본을 먼저 커밋하고, 다듬은 버전은 다음 커밋으로 올려서 GitHub의 diff로 무엇이 바뀌었는지 볼 수 있게 한다.
- 나중에 회수할 복선은 `설정/복선.md`에 기록한다.
