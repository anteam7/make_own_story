# make_own_story

직접 쓰는 글을 Claude와 함께 다듬으며 버전 관리하는 저장소.

## 작품

- [괴이박멸사무소](괴이박멸사무소/)

## 구조

```
괴이박멸사무소/
├── 본문/              회차별 원고 (001_도입부.md …)
└── 설정/
    ├── 작품개요.md     로그라인, 핵심 콘셉트, 세계관 규칙, 큰 흐름
    ├── 인물.md         주인공, 도플갱어, 동생, 부인, 악령, 연쇄살인마
    ├── 능력.md         세 가지 능력 체계
    ├── 타임라인.md     실제 사건 순서 / 독자 공개 순서
    ├── 복선.md         복선 심기·회수 관리
    ├── 장면메모.md     쓰기로 정한 핵심 장면과 연출 의도
    ├── 묘사원칙.md     격투 묘사·문장 기준
    ├── 미정사항.md     아직 결정 안 된 것들
    └── 원본메모/       러프 메모 원문 보관
```

## 작업 방식

- 원고를 수정할 때는 커밋을 나눠서 남긴다. 처음 쓴 원본을 먼저 커밋하고, 다듬은 버전은 다음 커밋으로 올려서 GitHub의 diff로 무엇이 바뀌었는지 볼 수 있게 한다.
- 나중에 회수할 복선은 `설정/복선.md`에 기록한다.
- 새 아이디어는 러프하게 `설정/원본메모/`에 날짜별로 던져 두고, 정리본은 각 설정 파일에 반영한다.
- 원고를 쓰거나 다듬을 때는 `설정/` 문서와 어긋나지 않는지 확인한다.
